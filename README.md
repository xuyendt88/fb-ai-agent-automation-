# 🤖 fb-ai-agent-automation

Hệ thống AI Agent tự động hóa toàn trình (End-to-End) dành cho các trang và nhóm Facebook, giúp cá nhân và doanh nghiệp tối ưu hóa quy trình thu hút, phân loại, chăm sóc khách hàng và vận hành phễu kinh doanh với chi phí tối thiểu.

## 🚀 Các tính năng cốt lõi
- **Data Ingestion & Enrichment Agent:** Tự động bắt dữ liệu đăng ký/khảo sát đầu vào từ mạng xã hội.
- **AI Lead Scoring:** Sử dụng **Google Gemini API** để phân tích nhu cầu và chấm điểm mức độ tiềm năng của khách hàng (HOT / WARM / COLD) một cách thông minh.
- **Centralized Database:** Đồng bộ hóa và lưu trữ dữ liệu thời gian thực trực tiếp lên Google Sheets, sẵn sàng cho đội ngũ hoặc các agent tiếp theo xử lý.
- **Lean Architecture:** Xây dựng bằng Python thuần và Flask, tối ưu hóa chi phí cố định bằng 0 đồng.

## 🛠 Tech Stack
- **Backend:** Python, Flask
- **AI Brain:** Google Gemini API (`gemini-2.5-flash`)
- **Database & Storage:** Google Sheets API (`gspread`)
- **Version Control & Hosting:** GitHub
